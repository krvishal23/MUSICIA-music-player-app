# 🎵 Musicia – Music Player App

Musicia is a modern and responsive music player built using **HTML, CSS, and JavaScript**. It provides a clean user interface and a smooth music playback experience with essential audio controls.

## ✨ Features

* 🎶 Play, pause, next, and previous track controls
* 🎧 Interactive music player interface
* 📜 Playlist support
* ⏱️ Progress bar with real-time updates
* 🔊 Volume control
* 📱 Responsive design for desktop and mobile devices
* ⚡ Fast and lightweight

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **JavaScript (ES6)**

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/musicia.git
   ```

2. Navigate to the project folder:

   ```bash
   cd musicia
   ```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
